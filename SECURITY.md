# Security policy

## Supported versions

Security fixes target the latest release and the `main` branch. Older releases
may not receive fixes; update to the latest release when possible.

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's
[private vulnerability reporting form](https://github.com/felipefoz/wirelint/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include the affected version, a description of the impact, and steps or a
minimal example to reproduce the issue. Please avoid sending credentials or
other sensitive data. Maintainers will review the report, follow up as needed,
and coordinate disclosure and any fix with you.
